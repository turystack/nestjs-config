# @turystack/nestjs-config

Schema-first typed configuration for NestJS: zod-validated process.env with a fully typed get().

## Installation

```bash
pnpm add @turystack/nestjs-config
```

### Peer dependencies

The host application provides these:

```bash
pnpm add @nestjs/common reflect-metadata zod
```

## Documentation

Options, API reference and examples:

**https://tury.dev/libs/nestjs-config**

## Development

```bash
pnpm install
pnpm typecheck
pnpm check
pnpm test
pnpm build
```
